Desafio Amigo Secreto
Este projeto é uma aplicação que organiza um desafio amigo secreto, onde os participantes são sorteados aleatoriamente para presentear outros participantes.

Sobre o Projeto
O objetivo do projeto é criar uma ferramenta simples e fácil de usar para gerenciar os sorteios dos amigos secretos. A aplicação permite que os usuários sejam adicionados, removidos e sorteados automaticamente.

Funcionalidades
Cadastro de Participantes: Permite adicionar novos participantes ao sorteio.

Remoção de Participantes: Possibilita remover participantes antes do sorteio.

Sorteio Aleatório: Realiza o sorteio dos amigos secretos garantindo que cada pessoa seja atribuída a outra diferente.

Visualização dos Resultados: Apresenta os resultados do sorteio, mostrando quem deve presentear quem.
